# 手机离线聊天

本版本接入固定版本的llama.cpp，手机本地运行官方Qwen2.5-3B-Instruct Q4_K_M GGUF。模型独立导入，不打包到IPA，不上传私人聊天和人物资料。App只对已配对的私人局域网电脑发起同步请求，推理不调用远程API。

## 安装模型

1. 使用相同Apple账号覆盖安装新版IPA，先备份聊天，不要卸载。
2. 在Windows iTunes文件共享中把官方模型放入App文稿，或将模型放入iPhone本地“文件”。
3. App“我→设置→导入离线模型”选择GGUF，等待复制与SHA-256校验完成。
4. 配对电脑同步人物记忆后断开Wi-Fi与蜂窝数据，发送文字或已识别的语音进行测试。

固定模型：Qwen/Qwen2.5-3B-Instruct-GGUF，修订7dabda4d13d513e3e842b20f0d435c732f172cbe；接受当前文件大小2,104,932,768字节及已核实的历史相同模型哈希。
文件：qwen2.5-3b-instruct-q4_k_m.gguf；2,104,932,768字节。
SHA-256：626b4a6678b86442240e33df819e00132d3ba7dddfe1cdc4fbb18e0a9615c62d。模型导入按完整文件计算哈希，文件大小约2.10GB。

## 行为和限制

- 推理上下文2048 token，回复最多160 token；根据相关性与重要程度选取部分记忆、最近消息，以控制内存。完整聊天和记忆继续保存，未承诺无限上下文。
- 生成在后台线程执行；新消息取消旧请求，切到后台取消生成；每次结束释放模型与上下文。不会伪造回复或把失败提示写成角色消息。
- 这次接入没有训练模型权重、自动抽取长期记忆或主动消息生成；电脑版仍管理人物记忆。人物风格和记忆效果需真机实测。
- 首次导入将文件复制至App沙盒，约需4.21GB用于两份模型，此外保留3GB系统余量。确认导入及重启后正常，再由用户删除源副本释放空间。
- 免费个人签名仍需定期续签。iPhone15的速度、发热和系统内存终止情况不能由云端编译测试替代。

## 构建

XcodeGen + macos-15 runner。固定llama.cpp提交553d2c2e7ec67307b44d6264ded5e3d6fce5b1b9，构建Metal设备/模拟器XCFramework。运行桌面测试、iOS单元测试，然后构建未签名IPA。运行库MIT许可证随App资源提供。

Desktop/data、模型、私人资源不纳入Git。公共仓库只保留通用程序和空种子记忆。局域网控制端为带配对令牌的HTTP，仅限可信私人网络，详见Desktop/README.md。
