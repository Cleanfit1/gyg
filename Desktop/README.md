# 免费电脑控制端

双击`Start-Controller.cmd`。此电脑优先使用D:\Python312\pythonw.exe，无需付费接口，不下载依赖。其他电脑需要带Tk组件的Python3。

## 同一Wi-Fi配对

1. 将整个Desktop文件夹保留在D盘；手机先安装本次更新后的IPA。
2. 手机和电脑连接同一个可信私人Wi-Fi。
3. 打开控制端的“手机连接”，检查显示的是电脑Wi-Fi的IPv4地址，不要使用VPN虚拟网卡地址。
4. 点击“开启局域网控制端”。如Windows询问防火墙访问权限，只允许私人网络。无需付费、无需路由器端口转发。
5. 复制配对链接，发送给自己的手机，在Safari打开，点击“打开小屁孩并配对”，允许App访问本地网络。
6. 回到电脑，检查最近同步时间。记忆页点击“接收手机记忆”；资料页点击“读取手机当前资料”，然后编辑并保存。
7. 手机上回到App前台时同步最新配置。电脑关闭时不影响已有手机聊天、录音和资料的使用。

## 隐私和限制

- 配对链接含随机访问令牌，只给自己的手机。手机仅接受10.x、172.16～31.x和192.168.x私人IPv4。
- 使用令牌认证的HTTP而不是TLS，局域网传输没有加密，仅用于可信私人Wi-Fi。不要在公共Wi-Fi配对，不要开放端口到互联网。
- 手机回传的phone-state.json包含聊天、记忆及头像，不含录音文件。它只存于本机data目录，已排除Git上传。
- 首次配对采用手机现有资料，避免空配置覆盖；后续以电脑保存的资料为准。记忆按更新时间合并，显式删除记忆前弹窗确认。
- 没有接入自动学习模型，人物参数只负责保存和同步，不代表会立即改变AI回复。
- 手机已移除记忆和模型管理页面，仍保留个人头像资料编辑、普通设置和聊天备份。
- USB文件共享作为备用通道保留：Documents中phone-state.json为手机快照，controller-config.json为配置输入。无需使用备用方式即可Wi-Fi同步。

## 测试

`python -B -m unittest discover -s Desktop -p 'test_*.py' -v`

覆盖无效配置保护、无令牌请求拒绝、手机状态回传、首次同步资料保护和非法参数拒绝。真实Wi-Fi、防火墙权限、iOS本地网络权限仍需用户设备验证。
